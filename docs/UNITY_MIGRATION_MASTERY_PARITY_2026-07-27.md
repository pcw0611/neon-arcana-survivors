# 마스터리 특수기 이식과 전투 유사도 교정 (2026-07-27)

작성자: Claude (웹 원본 `public/game-v4.js` 개발자). Codex로부터 Unity 마이그레이션을 인수인계받아 진행.

이번 작업의 기준은 하나다. **웹 원본과 최대한 똑같이 만드는 것.** Unity에 맞게 재해석하는 것이 아니라,
웹 원본 코드의 수치·판정 기하·발동 조건을 그대로 옮기는 것을 목표로 했다.

## 1. 이번에 고친 "이미 있었지만 원본과 다르던" 것

기존 구현은 동작은 했지만 원본과 수치·구조가 달라 체감이 크게 벌어져 있었다.

### 1-1. 실버불렛 기본 공격

| | 웹 원본 | 수정 전 Unity | 조치 |
|---|---|---|---|
| 탄 수 | 그대로(늘리지 않음) | `count * 2`로 **2배 증폭** | 증폭 제거 |
| 산탄 각도 | `spread = 0` (한 방향 고정) | 랜덤 ±2.5° 산탄 | 0으로 고정 |

원본에서 실버불렛의 정체성은 "한 방향으로 빠르게 몰아쏘는 연사"인데,
수정 전에는 탄이 2배로 늘고 무작위로 흩어져 오히려 산탄총처럼 동작했다.

### 1-2. 쉐도우마스터 광검 (가장 큰 차이)

원본은 **쌍검**이다. 플레이어가 실제로 들고 있는 두 검의 각도(정면 ±0.5 라디안)에서
각각 베어나가고, 잔상(`saber_echo`)이 붙으면 두 검에 번갈아 분배된다.

| | 웹 원본 | 수정 전 Unity | 조치 |
|---|---|---|---|
| 스윕 수 | `2 + 잔상` (쌍검) | 단일 부채꼴 1회 | 쌍검 스윕 구현 |
| 스윕 각도 | 정면 ±0.5rad | 조준 방향 1개 | 좌우 검 각도로 분리 |
| 좁아지는 대상 | 베기 **각도** (`SaberArc * 0.72`) | **사거리** (`SaberRange * 0.8`) | 각도로 정정, 사거리 왜곡 제거 |
| 피해 배율 | 스윕당 `1.35` | 전직 시 `SaberDamage * 1.3` | 스윕 단위로 이동(중복 제거) |
| 잔상 분배 | 두 검에 번갈아, 커버리지 상한 `0.85` | 단순 타격 횟수 증가 | 원본 분배 규칙 구현 |

커버리지 상한이 중요하다. 이게 없으면 잔상을 쌓을수록 사실상 360도 전방위 공격이 되어 밸런스가 붕괴된다.

### 1-3. 토르의 망치

수정 전에는 **마스터리 조건 없이 6초마다 무조건** 발동했고, 부가 효과가 전부 빠져 있었다.

| | 웹 원본 | 수정 전 Unity | 조치 |
|---|---|---|---|
| 발동 조건 | 연쇄 낙뢰 7랭크(마스터리) 달성 시에만 | 조건 없음 | 마스터리 게이트 추가 |
| 주기 | 8.5초 × 한계돌파 보정 | 고정 6초 | 원본 값 적용 |
| 쉴드 | **무시하고 본체에 피해** | 일반 피해(쉴드가 흡수) | 쉴드 무시 경로 추가 |
| 상태이상 | 3초 기절 + 감전 | 없음 | 기절/감전 구현 |
| 범위 | 주변에도 파급 | 단일 대상 | 주변 파급 추가 |

## 2. 이번에 새로 이식한 것 — 마스터리 특수기 4종

원본에는 각 빌드의 핵심 강화를 최대까지 찍으면 "마스터리"가 열리고, 주기적으로 특수기가 자동 발동한다.
**전직한 클래스에 따라 같은 빌드라도 특수기가 완전히 달라진다.** 이 시스템 전체가 미구현 상태였다.

발동 주기(원본 `masterySpecs` 그대로, 한계돌파 시 `interval` 배율로 단축):

| 빌드 | 선행 조건 | 주기 |
|---|---|---|
| projectile | `multishot` 7랭크 | 9.5초 |
| saber | `saber` 7랭크 | 7.5초 |
| orbit | `orbit` 7랭크 | 10.5초 |
| thor | 토르 전직 + `chain` 7랭크 | 8.5초 |

한계돌파 보정(원본 `masteryScale`): `피해 = 1 + 레벨×0.04`, `범위 = 1 + min(20,레벨)×0.02`, `주기 = 1 − min(20,레벨)×0.01`

구현한 특수기:

- **성좌포 (projectile)**
  - 실버불렛: 자신을 중심으로 사방에 무작위 난사. 탄 수 `26 + 한계돌파×3`, 전탄 치명타, 가속 적용.
  - 그 외: 가장 가까운 적 방향으로 화면을 가르는 관통 레이저(직선 판정, 피해 9배).
- **광검 (saber)**
  - 쉐도우마스터: 전방으로 뻗는 거대한 어둠의 검기(직선 판정, 광검 피해 3배).
  - 그 외: 자신을 중심으로 전방위를 베는 황금 휠윈드(광검 피해 2.4배).
- **위성 (orbit)**
  - 메카닉: 모든 위성이 표적으로 집결해 융합 레이저를 동시 발사하는 폭발(위성 피해 4.2배, 반경 확대).
  - 그 외: 위성이 표적에 돌진해 폭발(위성 피해 3.2배).
- **토르의 망치 (thor)**: 위 1-3 참고.

## 3. 추가로 맞춘 것

- 쉐도우마스터 그림자 은신 주기를 원본과 동일한 **9초 주기 / 2.5초 은신**으로 정정(기존 7초 주기 / 1.2초).
- 적에게 기절·감전 상태를 추가하고, 기절 중에는 이동·행동·공격이 모두 멈추도록 처리. 풀링 재사용 시 상태 초기화.

## 4. 이미 원본과 맞아서 건드리지 않은 것

- 연쇄 낙뢰: 토르 피해 배율(0.4 ≒ 0.28×1.4)과 반경(2.4 / 2.1)이 원본과 일치.
- 위성 강화 3종(초신성 방전·성환 요격막·맥동 성환): 직전 작업에서 이미 실제 전투 판정에 연결됨.

## 5. 남은 유사도 과제

- 사이버 리바이어던과 삼켜짐 던전 (미이식)
- 조련의 코어 / 길들인 보스 동료 (미이식)
- 보스 옵션 9종의 실제 행동 효과 전수 대조
- 오디오 (원본은 절차적 합성이라 Unity에서는 실제 음원으로 새로 설계 필요)
- 연출(파티클·셰이더) 밀도 — 현재는 원본 캔버스 이펙트를 `CombatPulse` 기반으로 근사

## 6. 이 작업에서 지킨 원칙

1. 원본 코드의 **수치와 판정 기하를 그대로** 옮긴다. "Unity답게" 재해석하지 않는다.
2. 눈에 보이는 무기 위치와 실제 타격 판정 각도는 반드시 일치시킨다.
3. 레벨업으로 계속 넓어지는 각도 공격에는 반드시 총 커버리지 상한을 둔다.
4. 원본에 없는 스탯 보정을 임의로 추가하지 않는다(중복 적용의 원인이 된다).
